# CloudCast Scope — user manual

The published manual for **CloudCast Scope**, a signal monitor and analyser for
NDI®, AES67 / Livewire audio-over-IP, HLS and SRT.

**Read it: https://cloudcastsystemsau.github.io/cloudcast-scope-manual/**

It covers the desktop application — scopes, video and audio measurement,
timing, recording and offline analysis, SCTE-104 — and, in §11, watching the
same analysers from a browser on your network.

This repository is a published copy. The manual is written as Markdown in the
product repository and built from there; corrections are welcome as issues.
